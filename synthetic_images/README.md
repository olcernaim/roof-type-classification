# Synthetic training images

The 33 synthetic roof images (11 training configurations of one image per class: flat, gable and hip), produced by the authors with Autodesk Maya, as used for the synthetic-training experiments. Configuration *N* is the set shown as *Test N* in Figure 7 of the previous article (Ölçer, Ölçer & Sümer, 2023, https://doi.org/10.7717/peerj-cs.1217). All images are 105 x 105 pixels and show the black bands that are visible in that figure.

File names inside each folder are `<class>_<original file name>`. The suffixes `_L`, `_R` and `_Top` of the original file names denote the three sun angles (left, right, top); files without a suffix carry no sun-angle label in the original file name. In configurations 6, 9 and 10 all three images are `_Top` renders and look nearly identical across the classes; in configuration 7 only the gable image is a `_Top` render.
